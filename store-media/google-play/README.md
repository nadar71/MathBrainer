# Math Brainer Google Play Media Pack

This directory contains publishing-ready media organized by Google Play Console asset type.

## Asset Inventory

- `icon/mathbrainer-store-icon-512.png` - 512 x 512 PNG store icon with no baked rounded corners or text.
- `feature-graphic/mathbrainer-feature-graphic-1024x500.png` - 1024 x 500 PNG feature graphic using the approved modernized identity.
- `phone-screenshots/` - 19 authentic 1080 x 2160 phone screenshots covering the home screen and every game.
- `phone-screenshots/SELECTION.md` - Recommended order for the primary eight-image phone gallery.
- `tablet-7-inch/` - Six authentic screenshots captured from a standard 7-inch tablet profile.
- `tablet-10-inch/` - Six authentic screenshots captured from a standard 10.1-inch tablet profile.
- `promo-video/SHOT-LIST.md` - A production-ready 30-second promotional video sequence.
- `promo-video/YOUTUBE-COPY.md` - Suggested YouTube title, description, and upload checklist.
